# Getting Started with MemVault

## Prerequisites

- Python 3.10 or higher
- pip
- Docker (optional, for containerized deployment or PostgreSQL)

## Installation

### Option 1: Library only (no local embeddings)

```bash
pip install memvault
```

You'll need to provide your own embedder or use the API mode.

### Option 2: With local BGE embeddings (recommended)

```bash
pip install memvault[local]
```

This downloads the BGE-small model (~130MB) on first use and
caches it locally. No API key required, runs entirely on your machine.

### Option 3: From source (development)

```bash
git clone https://github.com/Aryaneviloo/memvault.git
cd memvault
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -e ".[local,dev]"
```

## Your first memory

Open a Python shell and try this:

```python
from memvault.core.models import MemoryItem, MemoryQuery, MemoryType
from memvault.embeddings.local import LocalEmbedder
from memvault.storage.sqlite import SQLiteStorage
from memvault.storage.base import EmbeddingStorageWrapper
from memvault.core.retrieval import retrieve

# Build the stack
backend = SQLiteStorage("my_memories.db")
embedder = LocalEmbedder()          # downloads model on first run
store = EmbeddingStorageWrapper(backend=backend, embedder=embedder)

# Store some memories
store.insert(MemoryItem(
    agent_id="assistant",
    user_id="alice",
    type=MemoryType.SEMANTIC,
    content="Alice prefers concise answers over long explanations",
    importance=0.9,
))

store.insert(MemoryItem(
    agent_id="assistant",
    user_id="alice",
    type=MemoryType.EPISODIC,
    content="Alice asked about Python decorators on her first session",
))

store.insert(MemoryItem(
    agent_id="assistant",
    user_id="alice",
    type=MemoryType.SEMANTIC,
    content="Alice is learning Python and has 6 months of experience",
    importance=0.8,
))

# Retrieve by meaning
query = MemoryQuery(
    text="what do I know about this user's Python background?",
    user_id="alice",
    top_k=3,
)

results = retrieve(query=query, backend=backend, embedder=embedder)

for r in results:
    print(f"score={r.final_score:.3f} | {r.item.content}")
```

Expected output (order may vary slightly):

score=0.712 | Alice is learning Python and has 6 months of experience
score=0.681 | Alice asked about Python decorators on her first session
score=0.534 | Alice prefers concise answers over long explanations

Notice the first two results are about Python specifically,
even though the query didn't say "Python" — that's semantic search working.

## Using the REST API

### Start the server

```bash
# With Docker (easiest)
docker compose -f docker/docker-compose.yml up api

# Or directly
uvicorn memvault.api.app:app --reload --port 8000
```

### Store a memory

```bash
curl -X POST http://localhost:8000/memories \
  -H "Content-Type: application/json" \
  -d '{
    "agent_id": "assistant",
    "user_id": "alice",
    "content": "Alice prefers concise answers",
    "type": "semantic",
    "importance": 0.9
  }'
```

### Search

```bash
curl -X POST http://localhost:8000/memories/search \
  -H "Content-Type: application/json" \
  -d '{
    "text": "how should I respond to this user?",
    "user_id": "alice",
    "top_k": 5
  }'
```

### Explore the API docs

Open `http://localhost:8000/docs` in your browser for
interactive API documentation — you can test every endpoint
directly from the browser.

## Using the CLI

```bash
# Store memories
memvault remember "User prefers dark mode" --user alice
memvault remember "User is learning Python" --user alice --importance 0.8 --type semantic

# Search
memvault recall "what does this user like?" --user alice

# Consolidate near-duplicate memories
memvault consolidate --user alice --threshold 0.85

# Check system health
memvault doctor
```

## Memory types — when to use which

**`episodic`** — something that happened at a specific point in time.
Use for events, interactions, session notes.

"User asked about authentication on 2026-01-15"
"User completed the onboarding flow"

**`semantic`** — stable facts that don't expire quickly.
Use for preferences, background info, user profile facts.

"User prefers Python over JavaScript"
"User works in finance"

**`procedural`** — repeatable workflows or behavioral patterns.
Use for "how to do X for this user."

"Always provide code examples with explanations"
"User prefers bullet points over prose"

**`working`** — short-term session context.
Use for current task state, within-session notes.

"Currently debugging the auth module"
"User is in onboarding step 3"

**`consolidated`** — auto-generated by the consolidation pipeline.
Don't create these manually.

## Choosing a storage backend

```python
from memvault.storage.memory import InMemoryStorage    # tests / experimentation
from memvault.storage.sqlite import SQLiteStorage      # local dev / production
from memvault.storage.postgres import PostgresStorage  # production / multi-process
```

All three implement the same interface — switching is one line:

```python
# Development
backend = SQLiteStorage("memories.db")

# Production
backend = PostgresStorage("postgresql://user:pass@host:5432/dbname")
```

## Configuring retrieval

```python
from memvault.core.retrieval import RetrievalConfig
from memvault.core.scoring import ScoringWeights

config = RetrievalConfig(
    similarity_weight=0.6,    # weight semantic similarity more
    relevance_weight=0.4,
    min_similarity=0.3,       # filter out weak matches
    scoring_weights=ScoringWeights(
        recency=0.5,          # heavily favor recent memories
        importance=0.3,
        frequency=0.2,
    ),
)

results = retrieve(query=query, backend=backend, embedder=embedder, config=config)
```

## Running consolidation

Consolidation finds near-duplicate memories and merges them.
Run it periodically (e.g. once per session, or on a schedule):

```python
from memvault.core.consolidation import consolidate, ConsolidationConfig

result = consolidate(
    user_id="alice",
    backend=backend,
    config=ConsolidationConfig(
        similarity_threshold=0.85,  # how similar to merge
        min_cluster_size=2,
        max_cluster_size=10,
    ),
)

print(f"Merged {result.memories_consolidated} memories into {result.clusters_found} clusters")
```
